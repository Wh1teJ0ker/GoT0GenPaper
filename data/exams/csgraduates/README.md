## 格式约定

- 每份试卷一个 `.md` 文件，YAML front matter 含 `title` 与 `source` 原始链接。
- 数学公式为 LaTeX：行内 `$...$`，独立公式 `$$...$$`（含 `aligned`/`pmatrix`/`cases` 等环境）。由页面 KaTeX 渲染结果逆向还原，个别复杂结构可能与原始 LaTeX 措辞有出入。
- 选择题：题干 + `- A./B./C./D.` 选项 + `**【答案】X**`（多选以字母并列）+ `【标签】` 知识点标签 + `【解析】`。
- 解答题：题干 + `**【标签】...**` + `**【解析】**`（完整解答）。
- 填空处统一为 `______`；正文中的货币 `$` 已转义为 `\$`。
- 卷首的选择题答案速对表保留为表格（blockquote 内）。
